Opus / Sonnet / Haiku の使用量をリアルタイムで確認

セッションフォルダをドロップ
~/.claude/projects フォルダをここへ
または .jsonl ファイルを複数選択

データが見つかりませんでした。

使い方

  1. macOS の Finder で ~/.claude/projects フォルダを開く
    Finder → メニューバー「移動」→「フォルダへ移動…」→ ~/.claude/projects
  2. そのフォルダをこのページの上のエリアにドラッグ&ドロップ
  3. Opus / Sonnet / Haiku の残量がメーターで表示されます
